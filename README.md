# АРХИМЕД — углублённое изучение предметов и подготовка к олимпиадам

> Учебное веб-приложение (PWA) для 1–9 класса: математика, русский язык, физика, химия,
> информатика. Школьная программа берётся глубже учебника, приёмы разбираются на задачах
> Всероссийской олимпиады. Методика одна для всех предметов: **сначала объясни — потом реши**.

- **Приложение ученика:** https://123.teramont.pro/MVP/
- **Кабинет родителя:** https://123.teramont.pro/MVP/parent/
- **Витрина проекта:** https://s5hyhbpftv-alt.github.io/arhimed/

## Что в приложении

| | |
|---|---|
| Задач | **700** — русский язык 324 · начальная школа 188 · разбор с Мишуткой 57 · математика 41 · физика 41 · информатика 27 · химия 22 |
| Уроков в «Книге знаний» | **449** — информатика 150 · математика 138 · начальная школа 92 · физика 23 · химия 22 · русский язык 18 |
| Русское направление | 20 листов: уроки 601–610, проверочные работы 611–613, работа МЦКО 614, демоверсия 615, функциональная грамотность 616–618, словарные слова 619–620 |
| Мастерские Сиракуз | 6 уроков 4–9 классов: чётность, принцип Дирихле, игры и стратегии, инвариант, оценка и пример, крайний случай — по одному олимпиадному приёму на урок, у каждого задания свой сюжет и свой рисунок |
| Словарь | 362 слова на классы 1–6 |

Каждый урок — объяснение по кадрам со своей сценой, проверка понимания и тренажёр.
У задачи — подсказки-лестницей (намёк → ход → полное решение) и разбор с типовой ловушкой.
Ученику показываются уроки и задания его класса.

## Устройство

**Чистый JavaScript без сборщика.** Скрипты подключаются тегами с меткой версии `?v=NNN`,
она же в имени кэша сервис-воркера — так браузер не отдаёт старый код. Python нужен только
для выкладки, шлюза и проверок.

Два приложения на одном домене: детское `MVP/` и родительское `MVP/parent/` (отдельный код).
Связка «родитель — ученик» идёт по коду вида `ARH-XXXX-XX` и раздельным PIN.

| Что | Где |
|---|---|
| Точка входа, CSS оболочки, список скриптов | `MVP/index.html` |
| Роутер, экраны, «Путь», банк задач | `MVP/js/app.js` |
| Движок задач: ответ, проверка, награды | `MVP/js/engine.js`, `MVP/js/core.js` |
| Каталог «Учебники» и карточки уроков | `MVP/js/lessons.js` |
| Кабинет родителя | `MVP/js/dashboard.js`, `MVP/js/kid.js`, `MVP/parent/` |
| Помощник: аватар, голос, живой агент | `MVP/js/assistant.js`, `voice.js`, `agent.js`, `agentlive.js` |
| Данные уроков и рисовальщики кадров | `MVP/data/` (`vis_*.js` — сцены, `lessons*.js` — карточки) |
| Банк задач | `MVP/data/tasks*.js` |
| Шлюз: API прогресса + релей голоса | `шлюз_сервер.py` (aiohttp) |
| Выкладка на сервер | `deploy/deploy.py` |

Порядок подключения важен: данные грузятся раньше рисовальщиков —
`tasks*.js` → `lessons*.js` → `vis_*.js` → `js/*.js`.

## Запуск

```bash
cd MVP && python3 -m http.server 8123
# → http://127.0.0.1:8123/
```

Так работает всё, кроме кабинета родителя и голоса: им нужен шлюз.

```bash
ARH_DATA=/tmp/arh PYTHONPATH=.py-libs python3 шлюз_сервер.py 8135
# → http://127.0.0.1:8135/MVP/
```

Голосовой озвучке нужен ключ Яндекса — в файле `ключ_яндекса.txt` или переменной
`YANDEX_API_KEY`. В репозиторий ключ не попадает.

## Проверки

Своя система машинных проверок. Запускать из корня, нужен поднятый локальный сервер.

| Инструмент | Что проверяет | Норма |
|---|---|---|
| `qa_frame.py <урок> <кадр>` | геометрию кадра: наложения чернил, выход за края, сдвиг от якоря | «замечаний нет», ≈5 с |
| `qa_layout.py 601 … 618` | раскладку кадров на 390 и 320 px | «проблемных шагов 0» |
| `qa_ui.py` | контраст, кегли, цели касания, reduced-motion на 390/768/1200 | «нарушений нет» |
| `qa_feedback.py` | отклик на верный и ошибочный ответ во всех тренажёрах | 14 / 14 |
| `qa_ru.py` | данные уроков, банк задач, словарь, баллы МЦКО, раскладку | 93 / 93 |
| `qa_ru_trainers.py` | решаемость каждого пункта тренажёров через интерфейс | «10, без проблем 10» |
| `node qa_ru_items.js` | инварианты заданий проверочных работ | 84 задания, нарушений нет |
| `qa_tour.py` | олимпиадные туры: схема данных, сумма баллов, нумерация id, расхождения между `.md` и `.json` | «Расхождений нет», ≈1 с |

Тяжёлые наборы идут минутами — запускать в фоне и читать вывод из файла.

**Зелёный гейт не значит «сделано правильно».** Геометрия ловит «налезло» и «уехало», но не
ловит «некрасиво» и «не то, о чём просили» — снимок глазами обязателен.

## Выкладка

```bash
# 1. поднять версию во всех трёх местах
sed -i '' 's/v=605/v=606/g' MVP/index.html MVP/parent/index.html
sed -i '' "s/arhimed-mvp-v605/arhimed-mvp-v606/" MVP/sw.js
# 2. коммит и пуш, 3. выкладка
git add -A && git commit -m "…" && git push origin main
PYTHONPATH=.py-libs python3 deploy/deploy.py
```

Пропустить поднятие версии нельзя: `?v=NNN` и `CACHE='arhimed-mvp-vNNN'` — это и есть механизм
сброса кэша. Скрипт выкладки сам сверяет версию на сервере с локальным `MVP/index.html`.

Сервер: код разворачивается **из GitHub** в `/opt/arhimed`, systemd-сервис `arhimed`.
Доступы — в `deploy/deploy.local.env` (в репозиторий не попадает).

## Правила проекта

- **Выкладывать только на зелёных проверках.**
- Кегли по шкале 12/14/16/20/24/32/48, контраст ≥ 4,5:1, цели касания ≥ 44 px,
  `prefers-reduced-motion` обязателен для любой анимации.
- **Никаких шаблонов:** три одинаковые карточки в ряд, один каркас кадров на разные темы,
  центрированный герой по умолчанию, эффекты ради эффекта — запрещены.
- **Не выдумывать факты.** Числа и формулировки заданий — из исходника, а не по памяти;
  этимология — только общеизвестная.
- Правки касаются только своего направления: не «улучшать» попутно соседние уроки.
- Секреты в репозиторий не попадают.

## Что в репозитории нет

Репозиторий содержит **только приложение и инструменты** (`.gitignore` работает по белому
списку). Исследования рынка, прототипы островов, финансовая модель, питч, демо 3D-химии,
шрифты и голоса живут в рабочей копии проекта и сюда не выкладываются.
