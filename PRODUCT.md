## Platform

## Users

**Ученик 1–9 класса** — основной пользователь. Телефон, часто одной рукой, часто в классе.
Экран должен читаться без увеличения и попадаться пальцем без прицеливания.

**Родитель** — отдельное приложение (`MVP/parent/`). Связка с ребёнком по коду `ARH-XXXX-XX`
и раздельным PIN. Видит прогресс, слабые темы, лимиты, заметки.

**Инвестор** — читатель презентации `MVP/инвесторы-2026.html`. Аудитория смешанная и это
подтверждено владельцем: частный инвестор, читающий сам, и аналитик фонда, проверяющий
допущения. Значит крупный тезис на экране плюс раскрываемые подробности в одном файле.

## Product Purpose

Углублённое изучение школьных предметов и подготовка к олимпиадам: математика, русский язык,
физика, химия, информатика. Школьная программа берётся глубже учебника, приёмы разбираются
на задачах Всероссийской олимпиады.

Методика одна для всех предметов: **сначала объясни — потом реши**. Урок это объяснение
по кадрам со своей сценой, затем проверка понимания, затем тренажёр. У задачи —
подсказки-лестницей (намёк → ход → полное решение) и разбор с типовой ловушкой.

## Positioning

Работающее приложение в проде, а не презентация. 449 уроков и 700 задач уже собраны
и доступны по ссылке. Сложность не в приложении, а в конвейере контента и методике:
каждый кадр урока имеет свою сцену, общий шаблон в проекте запрещён.

## Capabilities and Constraints

- **Чистый JavaScript без сборщика.** Скрипты подключаются тегами с меткой версии.
  Внешних библиотек и CDN нет — все графики рисуются своим кодом на SVG.
- Порядок подключения: `tasks*.js` → `lessons*.js` → `vis_*.js` → `js/*.js`.
- Python только для выкладки, шлюза (`шлюз_сервер.py`) и проверок.
- Свой набор машинных проверок: `qa_frame`, `qa_layout`, `qa_ui`, `qa_feedback`,
  `qa_ru`, `qa_ru_trainers`, `qa_ru_items`. Выкладка только на зелёных проверках.
- **Числа инвесторских материалов приходят из `инвесторы/модель.py` → `модель.json`,
  подставляются `инвесторы/собрать.py` в `инвесторы/презентация_шаблон.html`
  и сверяются `инвесторы/проверка_чисел.py`.** Править надо шаблон, а не собранный
  `MVP/инвесторы-2026.html` — его перезаписывает сборка. Связку ломать нельзя.

**Данные по международному направлению** (собраны для этой работы, только открытые источники;
владелец сузил фокус до четырёх стран):

- **Беларусь:** 1 058,9 тыс. учащихся на начало 2025/26; **91,77 %** учатся
  в классах с русским языком обучения (2024/25).
- **Кыргызстан:** более 1,5 млн школьников; русскоязычных школ около 250 из ~2 300;
  **переполнение русскоязычных классов: 50–60 человек против 15–20 в киргизоязычных** —

- **Армения:** русский остаётся первым обязательным иностранным языком, но с 2024/25

  по открытым источникам установить не удалось — цифру не выдумывать.**

**Чего нет и что нельзя выдумывать:** отзывов, кейсов, платящих пользователей,
договорённостей со школами, международной выручки. Международное направление —
горизонт за пределами 36-месячной модели, решение владельца; числа модели не меняются.

## Product Principles

1. **Сначала объясни — потом реши.** Методика важнее содержания конкретной задачи
   и одинакова для всех предметов.
2. **Не выдумывать факты.** Числа и формулировки — из исходника, а не по памяти.
   Отсутствие данных называется отсутствием данных.
3. **Никаких шаблонов.** Форма следует содержанию; одинаковая форма для разного
   содержания — брак, а не экономия.
4. **Проверяемость.** Всё, что заявлено, подтверждается замером, прогоном или ссылкой.
5. **Честная оговорка сильнее обещания.** Встречные ветры называются прямо —
   это и есть довод в пользу доверия.

## Accessibility & Inclusion

Продукт смотрит ребёнок на телефоне. Обязательно: контраст ≥ 4,5:1, цели касания ≥ 44 px,
кегль основного текста ≥ 16 px, поддержка `prefers-reduced-motion`, раскладка без
горизонтального переполнения на 320, 390, 768 и 1200 px.
