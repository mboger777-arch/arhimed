# Записанная озвучка уроков 257 и 300

`narration.js` воспроизводит готовые MP3 через один HTMLAudioElement в документе урока.
Голос — `ru-RU-SvetlanaNeural`. Системный speechSynthesis в этих двух уроках не используется.
Остальные уроки и общий голосовой движок приложения не изменены.

У каждого урока `narration.json` содержит точный текст и фразы с темпом, высотой и паузой.
Вопросы: −4%, +5 Hz; радостные реплики: 0%, +8 Hz; объяснения: −5%, 0 Hz;
подсказки: −8%, 0 Hz. Это небольшие изменения подачи одного голоса, не отдельные персонажи.
Пунктуация и разговорные формулировки помогают движку строить естественные фразы.
Между фразами сохранены короткие паузы; числа и действия соответствуют заданиям.

Генерация из корня репозитория:

```sh
python3 -m venv /tmp/arhimed-voice-env
/tmp/arhimed-voice-env/bin/pip install edge-tts==7.3.1 miniaudio==1.71
# В PATH также нужен LAME CLI.
/tmp/arhimed-voice-env/bin/python deploy/generate_lesson_narration.py
node deploy/test_lesson_narration.cjs
```

Для генерации нужен интернет. При воспроизведении приложение загружает только собственные
MP3; ключи, вызовы TTS-сервиса и установка библиотек на устройство ребёнка не нужны.
Фразы декодируются, соединяются с паузами и кодируются одним MP3 (24 кГц, моно, 64 кбит/с).
Имя файла — первые 12 символов SHA-256 от JSON `[voice, segments]` без лишних пробелов.
После правки текста или подачи обновить имя в JSON; генератор проверяет его и строит manifest.
Старые MP3 удалять только после проверки, что manifest больше на них не ссылается.

Воспроизведение начинается непосредственно по нажатию. Повторное нажатие, новый шаг,
подсказка, ответ, выход или скрытие страницы останавливают прежнюю запись. Номер поколения
защищает от поздних событий отменённого воспроизведения. Ошибка загрузки показывает
понятное сообщение и позволяет повторить попытку; автоматической подмены голоса нет.
