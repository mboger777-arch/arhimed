# Урок 300 — Ореховый экспресс

Документ открывается адаптером `data/lesson_jun300_orehi.js` внутри приложения. Прямой вход возвращает в `index.html#lesson-300`.

- 6 сюжетных шагов: перенос орехов до 10, остаток, самостоятельное действие, устный счёт, разложение слагаемого.
- 3 тренажёра по 3 задания. Ответ фиксируется сразу, включая перезагрузку до кнопки «Следующее».
- `DB.lessons[300].nutExpress` — текущая сцена. Стандартные `tasks/stars/done/doneTs` — награды и отчёт родителю. Повторное решение не дублирует награду; перезапуск не удаляет достижения. Прежние два зачтённых задания остаются зачтёнными в журнале наград.
- CSS и обработчики изолированы документом урока. Общие движки не изменены. Возврат поддерживает «Путь» и каталог.
- Все рисунки созданы для этого урока по запросу владельца; WebP подготовлены из утверждённых оригиналов. Nunito — SIL OFL, лицензия рядом со шрифтом. Числа, орехи и ответы рисуются кодом, чтобы количество было точным.

Проверка адаптера: `node deploy/test_lesson300.cjs`. В браузере: все шаги, 9 заданий, неверный/пустой ответ, подсказка, перезагрузка посреди переноса и после верного ответа, повторение без повторных очков, выход, открытие 256/301. Проверены экраны 390×640/700/844 и 320×700. На коротком экране содержание может прокручиваться, кнопки навигации остаются внизу.

## Герои и действия (v929)

В начале друзья вместе держат корзинку. На этапах переноса Рыжик протягивает один орешек: нажатие отправляет его из лапки в пустую ячейку. Орех в лапке входит в сумму остатка; в корзине рисуется на один меньше. После заполнения лотка Рыжик радуется, отдельно видны оставшиеся орешки. Тоша показывает десяток, Рыжик с лупой помогает делить число; нажатие на героя вызывает штатную подсказку. В трёх тренажёрах разные ведущие, ответ меняет выражение героя и математическую иллюстрацию. В финале Тоша несёт готовую посылку. Пять новых прозрачных спрайтов созданы встроенным image_gen; точные запросы — ../257/HERO-PROMPTS.txt. Числа, награды и совместимость старого прогресса сохранены.
